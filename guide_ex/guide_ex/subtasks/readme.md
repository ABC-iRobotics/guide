# subtasks

The SUBTASK layer of GUIDE-EX: a meaningful part of a task, such as picking an object up or
placing it, made of sequences and steps. This folder holds no modules on this branch; the task
packages build their subtasks in their `solve_task.py`, e.g. `Pick` and `Place` in both
`guide_tasks/block_bin` and `guide_tasks/cube_stack`.
