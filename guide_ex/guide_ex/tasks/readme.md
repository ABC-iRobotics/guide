# tasks

The TASK layer of GUIDE-EX, below the organisation's PROCEDURE and SERVICE: operating a machine
or a transfer, such as moving a cube into a bin, made of subtasks. This folder holds no modules
on this branch; the task packages build their tasks in their `solve_task.py`, e.g.
`PickAndPlace` (`guide_tasks/block_bin`) and `PutOn` (`guide_tasks/cube_stack`).
