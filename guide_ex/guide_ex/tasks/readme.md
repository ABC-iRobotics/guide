# tasks

The TASK layer of GUIDE-EX, below the organisation's PROCEDURE and SERVICE: operating a machine
or a transfer, such as moving a cube into a bin, made of subtasks. The library's tasks are YAML
recipes in `guide_ex/recipes/task/` (`PickAndPlace`, block_bin's recorded episode; see
`recipes/CATALOGUE.md`); a task package's top recipe is its `config/recipes/Episode.yaml`.
